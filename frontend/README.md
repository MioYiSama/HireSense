# Frontend

## 路由

- `/` - 宣传页
- `/signin` - 登录页
- `/signup` - 注册页
- `/dashboard` - 仪表盘
- `/interview` - 面试页
- `/profile` - 个人档案/设置
- `/interview/:id/report` - 面试报告

## 认证

使用账号密码+AccessToken

## 仪表盘

- 为每个面试随机生成公司名字
- 汇总所有历史面试的成绩，绘制多个图表
- 尽可能从历史面试报告中分析出个人成长、能力评估、提升建议
- 根据历史面试结果，计算出用户不同方面能力的得分，然后为每个能力展示一定的提示信息（比如大于80分显示“你很优秀”，低于60分展示“系统设计能力相对薄弱”）
  - 通用能力评分（各维度满分10分）
    1. 逻辑思维
    2. 沟通表达
    3. 应变能力
    4. 自信度
    5. 学习能力
    6. 团队协同
  - 专业能力评分（各维度满分10分）
    - 前端岗位
      1. 设计
      2. 性能
      3. 工程化
      4. 组件化
      5. 数据流
      6. 安全
    - 后端岗位
      1. 分布式
      2. 性能
      3. 数据库
      4. API
      5. 安全
      6. DevOps

## 个人档案/设置

- 将用户提交的简历文件转换为纯文本
- 目标岗位只能选前端或后端
- “考官风格”提供预设模板（含“默认”）和自定义两种选择

## 面试页

提供语音输入、文本输入、轻量代码编辑器（CodeMirror）在线编写代码

## 面试报告

- 用雷达图展示能力评分
- 用列表展示复盘结果
